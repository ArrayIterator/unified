# Country flags — preview

Flag SVGs from [flag-icons](https://github.com/lipis/flag-icons) (lipis/flag-icons, MIT license —
see `LICENSE.flag-icons` in this directory; copyright (c) 2013 Panayiotis Lipiridis).
Both variants are shipped for every ISO 3166-1 country: `4x3/` (rectangular, 4:3) and
`1x1/` (square, 1:1). Served at `/assets/icons/flags/4x3/<code>.svg` and
`/assets/icons/flags/1x1/<code>.svg` (lowercase alpha-2 code). The single central registry
is `unified_core::reference_data::countries` (code -> name -> both flag files);
`GET /api/v1/reference-data/countries` lists it over HTTP.

249 ISO countries, 271 flag files per variant (the extra 22 files are non-ISO entities
flag-icons ships — `eu`, `gb-eng`, `gb-sct`, `gb-wls`, `arab`, `asean`, `cefta`, `eac`,
`es-ct`, `es-ga`, `es-pv`, `un` and similar — kept on disk for direct use, not in the registry).
