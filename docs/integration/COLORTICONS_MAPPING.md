Payment logos live with the payments module (like email logos live with the email module):
`src/modules/payments/logos/` holds one SVG per provider, a sprite (`logos/sprite.svg`, symbols
`provider-logo-payment-<id>`) generated by the provider-logos sprite builder, a `logos.rs` that embeds
the sprite at compile time, and a README with the real-vs-lettermark lists. The catalog returns the
stem only (`"logo": "payment-paypal"`), never a URL. Demo copies go to `demo/assets/logos/payment-*.svg`.

## Colour warning — read before approving

ColorTicons is NOT multi-colour. Two live samples (`building.svg`, `scale.svg`, fetched from the
repo) are verbatim Tabler outline icons: `stroke="currentColor" fill="none"`, 24x24 grid, 2px
stroke. The README, package.json and tags are all verbatim Tabler 2.11.0; nothing in the repo
indicates any colouring step. The "Color" in the name is not substantiated by any file inspected.
Replacing the previous multi-colour filled set with this set trades multi-colour filled icons for single-colour thin outlines
(one colour, inherited from text). If the user wants multi-colour, this set does NOT deliver it.
